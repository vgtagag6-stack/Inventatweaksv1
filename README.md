## 📥 Download

Grab the installer for your platform from the [latest release](https://github.com/vgtagag6-stack/Inventatweaksv1/releases/latest).
All builds are published to the release repository — **no sign-in is required to download**.

| Platform | Installer | Icon |
| --- | --- | --- |
| **Windows** | `.exe` (NSIS setup) or `.msi` | <img src="https://api.iconify.design/logos:microsoft-windows-icon.svg" width="18" alt="Windows" /> |
| **macOS** | `.dmg` | <img src="https://api.iconify.design/logos:apple.svg" width="18" alt="macOS" /> |
| **Linux** | `.AppImage`, `.deb` or `.rpm` | <img src="https://api.iconify.design/logos:linux-tux.svg" width="18" alt="Linux" /> |

## ✨ Features

| | Feature | Description |
| --- | --- | --- |
| 💾 | **System Backup** | Create restore points before applying any tweaks. |
| ⚡ | **Optimizations** | Latency, CPU, and RAM tuning options. |
| 🧹 | **System Cleanup** | Clear temporary files, DNS cache, and logs. |
| 🎮 | **Game Tweaks** | Dedicated tuning profiles for competitive titles. |
| 🛡️ | **Additional Settings** | Telemetry blockers and visual tweaks. |
| 🎯 | **Focus Mode** | Strip distractions and keep only what matters. |

| 🔄 | **Auto-update** | Fork-free updates straight from GitHub Releases. |

## 🚀 Build from Source

Requires [Node.js](https://nodejs.org/), [Rust](https://rustup.rs/), and the
[Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for your OS.

```bash
# install dependencies
npm install

# run the app in development
npm run tauri dev

# build a production installer
npm run tauri build
```
